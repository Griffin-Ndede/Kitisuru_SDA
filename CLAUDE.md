# Working notes

- Keep `README.md` up to date. After every significant change (new feature, setting, endpoint, route, dependency upgrade, deployment or security change), update the relevant README sections and add a dated entry at the top of the Changelog.
- Do not commit secrets or `.env` files. Configuration comes from environment variables (see `.env.example`).
- Work on a branch, run the tests (and lint and build for the front end) before committing.
